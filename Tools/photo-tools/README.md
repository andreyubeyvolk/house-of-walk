# Удаление фото с сайта

```
python Tools/photo-tools/remove_photos.py DPS_JAN25_0007 BKK_FEB25_0121          # проверка, ничего не меняет
python Tools/photo-tools/remove_photos.py DPS_JAN25_0007 BKK_FEB25_0121 --apply  # применить
```

Коды — те, что напечатаны на сайте (поездка_месяц_номер). Все удаляемые фото указывать
**одним запуском**, по текущей нумерации.

Скрипт сам: убирает фото из списка в `index.html` (нумерация, подписи, счётчик в шапке
пересчитываются сами), в эссе этой поездки удаляет сноски `[NNNN]` на удалённые фото,
остальные сдвигает так, чтобы они указывали на те же снимки, удаляет файлы `full`/`thumb`,
и перед записью сверяет через node: порядок и файлы оставшихся фото и цель каждой сноски
не изменились. При расхождении ничего не пишет.

После `--apply` стоит открыть сайт: счётчик в шапке, эссе этой поездки, ни одного 404.
