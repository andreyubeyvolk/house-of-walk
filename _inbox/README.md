# _inbox — буфер для нового контента

Сюда кидай всё новое: фото (JPG/WebP), обложки эссе, тексты. Раскладывай по подпапкам
(например `_inbox/tokyo/`) или кидай россыпью.

Claude забирает файлы, конвертирует в WebP (full + thumb / обложка 324x480),
кладёт в `photos/...`, подключает в index.html и после этого чистит содержимое.
Сама папка и этот файл остаются.

Содержимое в git не попадает (см. .gitignore) — коммитится только эта инструкция.
